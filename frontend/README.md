# Stack 01: React + Vite Hackathon Frontend Template

High-velocity, production-grade React 18 template conforming to the Universal Frontend Arsenal Contract and Owner's Strict Monochrome Design Lock.

## Architecture
- **Framework**: React 18 + Vite
- **Routing**: React Router v6
- **State Management**: Zustand
- **Server Cache**: TanStack Query
- **Styling**: Tailwind CSS with Design Tokens (Zero colored hues)
- **Typography**: Bell MT with Baskervville fallback
- **Offline Mock**: Full in-memory zero-config adapter

## Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Start development server with mock API
npm run dev

# 3. Lint strict monochrome theme
npm run lint:theme

# 4. Production build
npm run build
```
